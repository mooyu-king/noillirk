This policy describes our independent game edition and website analytics. No account, payment or evidence upload service is active.

Game and room data

The game API processes answers, scores, timestamps and a random participant credential to run the game. The hosted single-player API stores run state in Cloudflare Durable Objects with a 24-hour run lifetime. The local development API uses SQLite on the operator’s device; its local rooms expire after 10 minutes of inactivity and challenges after 30 days. Public multiplayer is not enabled. Expired records are removed through service cleanup. A restart does not extend round deadlines. Operator backups may retain earlier records until those backups are removed.

Browser storage

The browser stores the current run or room credential in session storage to reconnect after a refresh in the same tab. If storage is unavailable, you can still play in the current page, but refresh recovery may not work. Invite URLs do not contain participant credentials or answers. This browser also keeps up to 512 recently displayed question IDs in local storage, shared by game modes on this origin, until you clear site data. New games send these IDs to the game API to prefer unseen questions. They contain no answers or identity credentials; the API may retain them in its one-day request-deduplication record and operator backups. With storage disabled, history lasts only within the current page. This preference is not an anti-cheat system.

What other players can see

In local-development rooms, members see nicknames, connection status and revealed scores. Your unexposed answers are not sent to other participants. Local challenge links reveal the initiator's per-round scores only as the challenger completes those rounds.

Technical requests and analytics

Our services process ordinary request information for delivery and rate limiting. Hosting providers may also process technical request information.

We use Plausible analytics through the shared script at https://data.1back.link/js/app.js, sending traffic measurements to https://data.1back.link/api/send for noillirk.co. Requests may include page addresses, referring pages, device or browser information and network information such as an IP address. We use this service to understand visits and page usage. The embedded game is a separate document at /embed/ and uses the same site domain for analytics; its page loads do not mean a game has been started or completed.

We do not add free-text answers, nicknames, session credentials, screenshots or game saves as custom analytics fields. Do not put private information in page URLs. Privacy tools may block analytics. This integration does not send custom game-start or game-completion events.

Contact messages and deletion

If you email us, your email provider and ours process that message. Send only the information needed for your question. To request deletion or discuss privacy, contact mooyuking@gmail.com. Please do not email session tokens, passwords or private conversations.

External sites and changes

PlayDaily, Krillion and other external links have their own policies. This policy will be reviewed when services or data collection change.
